One funny name for a band made of robots, plus a few words on its hit song — picked by scoring a shortlist of original candidates against the house judge's published brief (real joke first, hit-song line adds a second laugh that fits the name, sounds like a band that could exist, few words, no explaining the joke) and writing the winner to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

The program is deterministic: no network, no randomness, no input. It writes exactly one line of UTF-8 text (1–200 characters, no trailing newline) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT` when set, for local runs).
